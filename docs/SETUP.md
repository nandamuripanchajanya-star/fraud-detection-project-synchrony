# FraudSense - Setup and Run Guide

## 1. Prerequisites

Install the following on the development machine:

- Python 3.13
- Node.js and npm
- PostgreSQL 18
- pgvector extension
- Git
- GitHub Desktop
- Visual Studio Build Tools with C/C++ build tools
- A Gemini API key

The project uses PostgreSQL with pgvector for semantic fraud-knowledge search.
